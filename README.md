<h1>🎬 YT-DLP-gui Downloader</h1>
<h2>A fast, lightweight, and easy-to-use video & playlist downloader built on yt-dlp, allowing you to download videos from multiple platforms with high quality and reliability.</h2>

<h3>🚀 Features</h3>

✅ Download videos and playlists

✅ Supports YouTube, Facebook, TikTok, Instagram, and many more

✅ High-quality video & audio formats

✅ Playlist & bulk download support

✅ Lightweight & fast

✅ Simple and user-friendly interface

✅ Built on yt-dlp (actively maintained)

<h3>🖥️ System Requirements</h3>
Windows 10 / 11

.NET Framework / .NET Runtime (if applicable)

Internet connection
<h3>📦 Installation</h3>
Download the latest release from:

https://github.com/ahmedfikrey/yt_dlp-gui


Extract the ZIP file

Run the application

Paste the video or playlist link

Click Download
